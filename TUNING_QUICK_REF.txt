                         TUNING TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Change ONE parameter at a time
✅ Small adjustments (±10%) work best
✅ Test 2-3 laps per change
✅ Keep notes on what works
✅ Backup before major changes

❌ Don't change multiple parameters at once
❌ Avoid large jumps (>25% change)
❌ Don't tune without testing
❌ Don't forget to document changes

                      QUICK WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Identify problem (which turn/intersection?)
2. Open tools/controller.py
3. Find relevant parameter in HYPERPARAMETERS section
4. Adjust value (small change first)
5. Save file
6. Run: python main.py
7. Test 2-3 laps
8. Document result
9. Repeat if needed
